## Build and contribute

Generated demos: edit the corresponding `prototypes/src` file, then run `node scripts/build-demo.mjs`. Presentation/gallery pages and SVG are directly authored. Do not edit generated outputs alone. Refresh affected previews and record the question, change, evidence and critique in [ITERATIONS.md](ITERATIONS.md).

For local browsing run `python3 -m http.server 8000`. No app install or framework packages are needed. Browser check scripts under `scripts/` use Playwright supplied by the contributor’s environment; the project does not bundle that runtime. See [CONTRIBUTING.md](../CONTRIBUTING.md) and [open challenges](CHALLENGES.md).
