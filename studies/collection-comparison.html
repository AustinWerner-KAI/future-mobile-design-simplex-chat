Set up a trial

Facilitator: task and observation guide

Counterbalance the six orders: grid/list/rail, grid/rail/list, list/grid/rail, list/rail/grid, rail/grid/list, rail/list/grid. Use one order per participant. Between forms, pause, choose the next layout and Start fresh trial; this clears the previous draft. Give no explanation of the design theory before tasks.

  1. “Find Alex and tell me what kind of connection Alex is.”
  2. “Go back. Find Maya and start a reply saying ‘I will check with Family.’ Keep it unsent.”
  3. “Look at Maya’s third photo, then go back to the reply you were writing.”
  4. “Return to your connections, then go back to that reply.”

Afterwards: “What stayed the same, and what changed?” Record the draft exactly, wrong turns, hints, ability to find the third photo, return position and preference with reasons. Do not suggest an answer.

Optional interruption: switch apps and return without reload. Record eviction separately from navigation loss. Test the person’s normal large-text setting and screen reader where applicable; CSS scaling is not a substitute.
