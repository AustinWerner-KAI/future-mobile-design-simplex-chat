Profile

Whose connections fill the home. A mark at the top left, no name in the header. Each keeps its own search, scroll and drafts.

Hidden profile

Out of the list behind a password. Unhidden by typing the full password into search. Never confirmed to exist.

Incognito

A random name for one new connection, chosen once with the name shown, fixed afterwards, named only in the composer.

Unverified

Whether an incognito name can be changed later, and whether the contact can tell. Maintainer question.

Static study. Nothing here creates a profile, stores a password or connects to anyone. Measured for 44 px targets and a 12 px text floor; see the mobile audit log.
