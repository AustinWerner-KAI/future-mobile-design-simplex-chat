Four recognisable identities

Individuals use one circular identity. Each connection has its own monogram. Small group, publication and storefront symbols identify the entity type alongside distinct container shapes. Text labels reinforce the differences; audience and transport remain explicit inside each workspace.

Candidate options, not validated outcomes. Shared fictional fixtures and local simulations. No real QR data in identity marks. Reload clears state. V2 is the earlier reference baseline.

These mockups work. Try the flow.

  1. Open Maya, write a reply draft, switch to Proposal, then return home. Your draft stays in this page.
  2. Open Harbour Café, choose Email, expand “Bring a detail to Maya”, edit and review the exact text before simulated sharing.
  3. In 2.1.1 expand favourites and compare Grid/List. In 2.1.2 use the strip arrows. In 2.1.3 use Arrange to create an overlapping collection.

Each preview is an independent session. Resetting it or reloading clears its fictional state. Nothing is sent externally.
