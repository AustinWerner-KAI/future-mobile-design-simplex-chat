# Claude project entry point

Read [the handoff](docs/CLAUDE_HANDOFF.md) before changing this project, then follow [AGENTS.md](AGENTS.md). The latest edit is **V2.1.2.3** ([record](docs/V2_1_2_3.md), [whole story](showcase.html)), not V2 and not the V2.1.2.1 gallery, which is its 4 October 2026 state. Preserve the design journey and evidence boundaries. Human relationships organise the interface; the octopus theory is the architecture of the flow.

**Read [the research notes](docs/RESEARCH_NOTES/README.md) before any change, and cite the relevant note and section in every pull request and audit log entry.** Start with the whitepaper [Interfaces That Arrive](docs/RESEARCH_NOTES/INTERFACES_THAT_ARRIVE.md): section 9 (the frame) and section 10 (what changes). For the home, the chat list or anything that shows more than one chat, read [Chat scrolling](docs/RESEARCH_NOTES/CHAT_SCROLLING.md) first.

Use [NEXT_STEPS](docs/NEXT_STEPS.md) as the durable task tracker and [MOBILE_AUDIT_LOG](docs/MOBILE_AUDIT_LOG.md) as the one running audit record. Edit `prototypes/src/v21/` and rebuild; add a check that fails on the pre-fix build for every behaviour you change. Ask Austin which open task to implement if no task is supplied; do not turn a handoff into an unsolicited redesign.
